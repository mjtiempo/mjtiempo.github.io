# mjtiempo.github.io

Personal portfolio site hosted on GitHub Pages.

## Projects featured

- **[markmeet](https://github.com/mjtiempo/markmeet)** — Meeting manager for Jitsi Meet using token auth (Python / Flask).
- **[omarchy-clippy](https://github.com/mjtiempo/omarchy-clippy)** — Clipboard history picker for the Omarchy bar (QML).

## Develop

The site is plain HTML/CSS — just open `index.html` in a browser (or serve it):

```sh
python3 -m http.server 8000
```

Deploy is automatic: push to `main` and GitHub Pages serves it at <https://mjtiempo.github.io/>
